# 星笺开发文档

星笺是一本放在本机的手帐。笔记、日记、时光、行迹和图片都写成文件，不使用数据库。界面按皮肤切换，今日页会按这台电脑的位置显示天气。

当前安装包面向 Apple 芯片的 macOS。

## 环境

- macOS（Apple 芯片）
- Node.js 20 及以上。Node 装在系统里，不放进项目。
- 依赖只安装在项目的 `node_modules`。删掉整个项目目录，应用、依赖和开发时的手稿会一起消失。
- 打包定位程序需要本机的 Swift 命令行工具（`swiftc`）。

## 目录

| 路径 | 作用 |
| --- | --- |
| `src/` | 页面、皮肤、天气图和界面状态 |
| `electron/` | 窗口、菜单、手稿读写和定位 |
| `shared/` | 页面和主进程共用的手稿结构 |
| `server/` | 开发时给浏览器提供同一份手稿的接口 |
| `data/` | 开发时的手稿。`vault.json` 是正文，`media/` 是图片 |
| `dist/` | 页面的构建结果 |
| `dist-electron/` | 主进程的构建结果 |
| `build/` | 图标和定位小程序 |
| `release/` | 打出来的安装包 |
| `scripts/` | 图标、定位程序和安装包用到的脚本 |

页面从 `src/view/shell.tsx` 进入。今日、笔记、日记、时光、行迹、素材和皮肤各自一个文件。

## 本地开发

第一次先安装依赖：

```bash
npm install
```

打开正在开发的窗口：

```bash
npm run desktop
```

也可以双击项目里的 `打开星笺.command`。这两条都会用项目里的 Electron 打开已经构建好的页面，手稿仍写在项目的 `data/`。

边改边看：

```bash
npm run dev
```

这条会同时启动页面服务和窗口。不要再另开一个星笺窗口，两个进程会一起写 `data/vault.json`。

检查类型：

```bash
npm run typecheck
```

## 手稿存在哪里

开发时：

```text
项目/data/vault.json      正文
项目/data/media/          图片
项目/data/backups/        手稿备份，保留最近 12 份
项目/data/exports/        导出的文稿
项目/data/runtime/        窗口缓存，可以删
```

写入时先写临时文件再替换，避免写到一半损坏。文件坏了会把原文移进 `backups/`，再开一册新的。

从安装包打开的星笺不读写项目目录。它的手稿在：

```text
~/Library/Application Support/星笺/data/
```

删掉这个 `星笺` 文件夹，安装版的手稿和缓存就没有了。开发目录里的 `data/` 不会被安装包改动。想把开发时的内容带进安装版，退出星笺后，把项目 `data/` 里的 `vault.json` 和 `media/` 复制过去。

## 打包安装包

在项目目录执行：

```bash
npm run dist:mac
```

这条命令会重新画图标、编译窗口和定位程序、构建页面，然后做出一个磁盘镜像。完成后文件在：

```text
release/hoshisen-1.0.0-arm64.dmg
```

打开镜像，把「星笺」拖进「应用程序」文件夹。第一次打开如果系统提示无法验证开发者，到「系统设置 → 隐私与安全性」里选择仍要打开。定位第一次会询问是否允许，允许后今日页才会出现所在城市。

安装包没有做 Apple 公证，所以不能直接发给不认识这台电脑的人就双击通过。本机使用是可以的。

## 定位和天气

今日页的城市来自系统定位，不是网络地址。人从上海到了南京，回到窗口或大约两分钟后，天气会换成南京。

定位由 `build/LocationHelper.app` 完成，安装包会把它放进应用里。城市名对照 `src/lib/city-book.ts`。天气数字来自 Open-Meteo，失败时横幅仍按钟点显示一幅天色。

## 皮肤

皮肤编号在 `shared/types.ts`，名字和句子在 `src/lib/skins.ts`，颜色在 `src/styles/global.css`。当前有晴窗、樱信、潮灯、夜笺、夜探、春日、远航、墨格、霆甲。选中的皮肤同时记在手稿和本机，下次打开不用等手稿读完才上色。

人物图在 `src/assets/cast/`，都是为星笺画的，不要换成现成作品里的角色。

## 代码约定

- 用 TypeScript。
- 用 `const` 和 `let`，不用 `var`。
- 函数写成箭头函数，并写上 JSDoc。
- 函数名以 `wpc_` 开头。组件因为要给 JSX 使用，写成 `Wpc` 开头，例如 `WpcToday`。
- 先用项目里已经有的函数，不另加一套用途相同的工具。
- 不引入 4.0.0 以前的 lodash。
